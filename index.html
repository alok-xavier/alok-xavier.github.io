GitOps on Amazon EKS

A side project that runs the OpenTelemetry demo shop, a set of microservices, on EKS. Every layer is declared in Git, from the cluster to the image tag, and nothing reaches the cluster by hand.

  1. Terraform

    Provisions the VPC and EKS cluster from reusable modules. State lives in S3, locked with DynamoDB.

  2. GitHub Actions

    On each pull request: build, unit tests and lint, then a Docker image tagged with the run ID.

  3. Git

    CI writes the new image tag into the Kubernetes manifest, so Git is the record of what should be running.

  4. Argo CD

    Watches the manifests and syncs every change into EKS. Rollback is a git revert.
